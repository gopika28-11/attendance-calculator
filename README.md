# Attendance-calculator
Smart Attendance Calculator built using HTML, CSS, and JavaScript. It calculates current attendance, predicts allowable leaves, and determines required classes to maintain target percentages like 75% or 85%.
## What It Does

- Enter total classes held and classes attended
- Choose a target attendance percentage (e.g. 75%)
- Instantly calculates your current attendance percentage
- Shows how many more classes you need to attend (or can safely skip) to stay above your target

## Why I Built This

Attendance requirements are a real, recurring stress point for students This tool removes 
the manual math and gives an instant, clear answer.

- HTML, CSS, JavaScript
